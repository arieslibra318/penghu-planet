# 澎湖小行星 Penghu Planet

在一顆小小的澎湖星球上探險的網頁遊戲：騎單車逛白沙、西嶼、馬公、湖西的景點蓋章，從馬公港或赤崁碼頭搭船到吉貝、桶盤、虎井、望安、七美，找回五顆「星火」，最後一起看海上花火節。

**線上遊玩：** https://arieslibra318.github.io/penghu-planet/

## 怎麼玩

| 操作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 | WASD／方向鍵（Shift 快跑） | 左下搖桿（推到底快跑） |
| 說話、查看、蓋章 | E | 互動 |
| 跳 | 空白鍵 | 跳 |
| 騎腳踏車 | B | 單車 |
| 星球地圖 | M | 右上地圖按鈕 |
| 時間快轉（看潮汐、夜景） | T | 右上太陽按鈕 |
| 拍照 | P | 右上相機按鈕 |
| 任務清單、集章護照 | J | 右上選單按鈕 |

進度存在瀏覽器的 localStorage，同一台裝置、同一個瀏覽器下次打開可以「繼續旅程」。

## 內容與資料來源

- 景點介紹依公開資料整理，大部分景點卡片下方附有參考資料連結；遊戲內「設定與說明」頁有完整說明。
- 主要來源：澎湖縣政府文化資產手冊、澎湖國家風景區管理處、林業及自然保育署、維基百科，以及《微笑台灣》、關鍵評論網、TVBS、蕃新聞等媒體與旅遊報導。
- 人物、對話與「星火」故事是虛構的；地圖距離與島嶼大小是示意；遊戲中的潮汐是簡化模型，實際前往請查中央氣象署潮汐預報並遵守現場管制（例如赤嶼禁止登島）。
- 資料整理於 2026 年 10 月。

## 技術

- 單一 `index.html`，不需要建置工具。
- 3D 使用 [three.js r128](https://threejs.org/)（MIT 授權，從 cdnjs 載入）。
- 字型：Google Fonts 的 Huninn（jf open 粉圓）與 Fredoka，皆為 SIL Open Font License。
- 音樂與音效都是瀏覽器即時合成，沒有外部音檔。

## 發佈到 GitHub Pages

1. 把 `index.html` 和這份 `README.md` 放進 repo 根目錄並推上 GitHub。
2. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，頁面上方會出現網址。
